# Contributing to Brain Tumor Detection App

First off, thank you for considering contributing to this educational project! 

## How to Contribute
1. **Fork the repository** and create your branch from `main`.
2. **Set up the environment**: Run `pip install -r requirements.txt`.
3. **Make your changes**. 
4. **Test your code**: Run `pytest tests/` to ensure you haven't broken existing logic.
5. **Update Documentation**: If you add new UI features, please describe them in the `README.md`.
6. **Submit a Pull Request**: Detail what you changed and why.

## Code of Conduct
Please be respectful and constructive in your feedback and code. This project is for educational use. Do not attempt to add features positioning this as a clinical diagnostic tool.
